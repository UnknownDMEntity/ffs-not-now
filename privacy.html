Privacy

FFS is designed as a local-first Windows utility.

FFS does not collect or upload

  • telemetry or analytics
  • screen contents or screenshots
  • keystrokes or typed text
  • browser history or tabs
  • document contents
  • application or process names
  • meeting, call or game activity
  • usernames or computer names
  • wellbeing-completion data

Local Windows state used

Idle detection asks Windows how long it has been since normal keyboard/mouse input. Fullscreen awareness compares active-window bounds with display bounds.

Internet access

Automatic update checks are off by default. Once an update endpoint is configured, a check runs only when you request it or enable automatic checks. FFS does not silently download or install updates. Support links only open when you choose them.

Diagnostics

The safe diagnostic summary is generated locally and excludes identifying account/device details, paths, IP addresses, app names, browser data and personal files.

Local settings

Your preferences are saved in a settings file on this Windows account. FFS does not upload that file.

This website and GitHub services

This site adds no analytics scripts or tracking cookies. GitHub hosts the website, support forms and update manifest. Visiting them or checking for updates gives GitHub normal connection information, including your IP address. The update request also identifies the FFS version in its user-agent header. See GitHub's privacy statement.

Bug reports, feature requests, comments and attachments submitted to the public repository are public and associated with your GitHub account. FFS sends no diagnostic reports automatically. Review anything you choose to paste or attach.
