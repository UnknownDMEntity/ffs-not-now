Privacy

FFS is designed as a local-first Windows utility.

FFS does not collect or upload

  • telemetry or analytics
  • screen contents or screenshots
  • keystrokes or typed text
  • browser history or tabs
  • document contents
  • application or process names
  • meeting, call or game activity
  • usernames or computer names
  • wellbeing-completion data

Local Windows state used

Idle detection asks Windows how long it has been since normal keyboard/mouse input. Fullscreen awareness compares active-window bounds with display bounds.

Internet access

Automatic update checks are off by default. Once an update endpoint is configured, a check runs only when you request it or enable automatic checks. FFS does not silently download or install updates. Support links only open when you choose them.

Diagnostics

The safe diagnostic summary is generated locally and excludes identifying account/device details, paths, IP addresses, app names, browser data and personal files.

Local settings

Your preferences are saved in a settings file on this Windows account. FFS does not upload that file.

This website and GitHub services

This site adds no analytics scripts or tracking cookies. GitHub hosts the website, support forms and update manifest. Visiting them or checking for updates gives GitHub normal connection information, including your IP address. The update request also identifies the FFS version in its user-agent header. See GitHub's privacy statement.

Feedback drafts and email

The Help & feedback page prepares your message in your browser. Typing, reviewing, copying or saving a draft does not upload it. This page does not store drafts automatically; keep a copy before leaving. Review any text you add, including diagnostic information, before sharing it.

Choosing Open an email draft asks your email app to prepare a message to ffsnotnowhelpdesk@outlook.com. You review it and send it yourself. If no email app opens, you can copy the message into your usual email service. Long messages may need a text-file attachment that you add yourself.

When you send feedback, the FFS support inbox receives your email address, message and any attachments you choose to include. We use them to understand your feedback and reply where needed. Email feedback is not automatically published as a GitHub issue. The support inbox is hosted by Microsoft Outlook.com; your email provider and Microsoft handle email delivery and storage. See Microsoft's privacy statement. Do not send passwords, personal documents or confidential workplace information. FFS submits no reports automatically.

Optional links under Advanced open GitHub's public issue forms. Bug reports, feature requests, comments and attachments submitted there are public and associated with your GitHub account. Signing in does not make them private. FFS sends no diagnostic reports automatically.
