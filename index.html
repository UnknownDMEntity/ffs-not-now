FFS, Not Now!

A small Windows utility that reminds you to look away, move occasionally and remain biologically attached to your chair in a sensible way.

Download for Windows Release notes Privacy Feedback
v0.9.5.4 pilot: New users get Windows sign-in startup and Toast reminders after the first launch. Existing preferences are kept. This portable test release is unsigned. Update checks are optional; downloading and switching versions remain manual.

Privacy first

No telemetry, accounts, screenshots, keystrokes, app-name inspection or meeting detection.

Smart timing

Natural breaks reset timers, proper breaks are tracked separately, and missed reminders do not become break debt.

Your level of annoying

Toast, reminder window, snooze, pause, fullscreen handling, themes and selectable personality.

What FFS actually watches

Very little, deliberately. Idle detection asks Windows how long it has been since normal keyboard/mouse input. Fullscreen awareness compares active-window size with the display. It does not identify the app.

Installation

  1. Save the EXE in a permanent local folder.
  2. If an older FFS is running, choose Exit from its tray icon.
  3. Open the new EXE. Use its tray icon → Settings → About to check the version.

No separate .NET installation is needed. On its first launch, FFS enables Windows sign-in startup for new users and defaults to Toast reminders. Existing saved choices are retained. Change these options in Settings → General and Save.

Keep the EXE in its permanent local folder. If you move it, launch it from the new location to refresh its startup path.

To remove the portable app, disable Start with Windows and Save, then Exit and remove its local copy. Preferences are retained.

Optional update checks

In Settings → About, choose Check for updates, or tick Automatically check for updates when FFS starts and Save. FFS checks version information and offers the release page. Checks are off by default.

The app is portable. Windows installer and Microsoft Store distribution are planned separately.
