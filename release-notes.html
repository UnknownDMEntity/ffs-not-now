Release notes

v0.9.5.4 — pilot

Published October 14, 2026. Windows x64 portable pre-release.

  • Windows sign-in startup is enabled for new users after the portable EXE is first launched.
  • Toast remains the default reminder style; saved startup and reminder choices are preserved.
  • Change these options in Settings → General and Save. Keep the EXE in a permanent local folder.
  • Automatic update checks remain optional and off by default; downloads and switching versions remain manual.

The EXE is self-contained and unsigned. The owner confirmed launch and saved preferences on the development laptop. Its startup entry was verified to point to the new EXE. DeepAV classified this binary there; the owner saved an exact-hash false-positive entry and the restored file matched the original checksum. This pilot does not establish compatibility with every protection product.

v0.9.5.3 — pilot

Published October 14, 2026. Windows x64 portable pre-release.

  • Privacy and Release notes viewers preserve paragraphs and bullet points.
  • Bug and suggestion buttons open the FFS feedback page with the matching category.
  • Feedback prepares an email draft for your review and send, or a text file; no GitHub account is needed.
  • Optional startup/manual update checks now use the published pilot version. Downloads and switching versions remain manual.

The EXE is self-contained and unsigned. The owner confirmed successful launch and readable viewers on a second test machine without an antivirus block. DeepAV classified this binary on the development laptop, where an exact-hash false-positive entry was saved. This is a pilot result, not a guarantee for every protection product.
